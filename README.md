## Installation

### Clone the Repository

```bash
git clone https://github.com/suhnshaine/IT0049-TFA6.git
```

### Navigate to the Project Folder

```bash
cd IT0049-TFA6
```

### Install Dependencies

```bash
composer install
```

## Running the Application

Start the development server:

```bash
php artisan serve
```

Open:

```text
http://127.0.0.1:8000/
```
